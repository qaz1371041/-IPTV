# 📺 IPTV Auto Update

全自动 IPTV 直播源聚合与每日自动更新系统。基于 GitHub Actions 实现**零人工干预**运行，并独创**双轨极简清理机制**，确保仓库无论运行多久，始终保持极致轻量。

---

## ✨ 项目亮点

- 🔄 **每日自动更新**：通过定时任务自动抓取、校验、聚合直播源
- 🧹 **双轨极简机制**：Git 提交历史与 Actions 运行日志自动裁剪，**永久仅保留最新 5 条**
- 🐍 **Python + FFmpeg**：智能检测直播源有效性，自动过滤失效链接
- ☁️ **零存储成本**：彻底告别历史堆积导致的仓库膨胀问题

---

## 🚀 技术架构

| 模块 | 说明 |
| :--- | :--- |
| **核心引擎** | Python 3.11 + FFmpeg 源质量检测 |
| **CI/CD** | GitHub Actions（定时 cron + 手动触发） |
| **历史裁剪** | `git filter-branch` 根节点重构 + `git gc` 深度清理 |
| **日志清理** | `gh` CLI 调用 GitHub REST API 批量删除旧 Workflow Runs |
